# 🔄 Two Cursors String Converter

## 📌 Описание

Проект реализует алгоритм обработки строки с использованием техники **двух указателей (leftCursor, rightCursor)**.

Алгоритм проходит строку с двух сторон:

* левый указатель движется с начала
* правый — с конца

Если оба указателя указывают на **буквы**, они меняются местами.

---

## 🧱 Структура проекта

```
src/
 └── com/
     └── example/
         ├── Main.java
         └── convertor/
             └── StringConvertor.java
```

* **Main** — точка входа в приложение
* **StringConvertor** — содержит основную бизнес-логику алгоритма

---

## 🧠 Логика работы

* если символ не является буквой → указатель пропускает его
* если оба символа — буквы → выполняется `swap`
* цикл продолжается, пока указатели не встретятся

---

## ⚙️ Пример

**Вход:**

```
J@va the be$t!123
```

**Выход:**

```
t@eb eht av$J!123
```
